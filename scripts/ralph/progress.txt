The app has no neighborhood code; "East Village" is hard-coded in `PlaceList.tsx` (eyebrow, masthead) and `PlaceDetail.tsx` (Maps query). Known out-of-area places are listed in the archived launch progress lines 338 to 441.

Mint a session by signing a random sid with `cookie-signature` and `SESSION_SECRET`, writing `sess:<sid>` to Redis with the JSON the Express login writes, and sending `connect.sid=s:<signed>`. - Admin server actions (`apps/admin/lib/actions/{places,tags,neighborhoods,photos}.ts`) follow one shape: `await requireAdminMutation()`, read the FormData, validate with `setFlash('error', …)` + `redirect(returnTo)` on failure, write through `@eve/db`, `revalidatePath`, `setFlash('success', …)`, `redirect`. Admin API routes guard with `requireAdminRequest(req[, { mutation: true }])` and answer errors through `adminErrorResponse(err)`.
- Admin UI pieces: `components/CollapsibleSection.tsx` (native `<details>`), `components/Notices.tsx` + `lib/notices.ts` (feedback stack), `components/SubmitButton.tsx` (`useFormStatus`, also disables on `useStale()`), `components/PlacePhotos.tsx` (photo strip, outside the form), `components/PlaceForm.tsx` (Basics, Tags, web fields, Editorial with Generate/Redo, aside), `components/NeighborhoodPicker.tsx` and `TagPicker.tsx` (inline create). Design tokens from `@eve/design-tokens` via `apps/admin/tailwind.config.ts`; no dark theme in the admin.
- Generate editorial: `POST /api/admin/generate` (`app/api/admin/generate/route.ts`) takes `{ place_id, fields, form }` and returns `{ fields, searches, warnings }`; prompt and validator in `lib/editorial.ts`, SDK call in `lib/generate.ts` (`claude-sonnet-5-5`, web search capped at 3).
